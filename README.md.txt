# Power BI Sales Dashboard

## Project Overview
This project is a Power BI dashboard created to analyze sales performance and provide insights into revenue, customer trends, product performance, and business growth.

## Objective
The goal of this dashboard is to:
- Track key sales KPIs
- Analyze sales trends over time
- Identify top-performing products and regions
- Understand customer behavior
- Support data-driven decision making

## Tools Used
- Power BI Desktop
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- Excel / CSV (Data Source)

## Dataset
The dashboard uses sales data containing information such as:
- Order details
- Customer information
- Product categories
- Sales amount
- Profit
- Region and date information

## Dashboard Features
- Sales overview dashboard
- KPI cards for Total Sales, Profit, Orders, and Customers
- Monthly/Yearly sales trend analysis
- Product category analysis
- Regional performance analysis
- Interactive filters and slicers

## Data Transformation
Data preparation was performed using Power Query:
- Removed duplicate records
- Cleaned missing values
- Changed data types
- Created calculated columns

## DAX Measures
Some key measures created:
- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Average Sales
